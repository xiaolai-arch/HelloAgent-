## 0. 阶段一知识地图

```text
        W1 LLM 原理（地基）
        Transformer / 注意力 / 采样 / MoE / 多模态
                        │
                        │ 一切交互都走 chat/completions 的 messages 数组
                        ▼
        W2 Prompt 与上下文工程（怎么把话说明白）
        LangGPT / Zero-Few-CoT / System 角色 / 结构化输出
                        │
                        │ 上下文窗口有限 → 外部知识要"选材"
                        ▼
        W3 RAG（怎么把对的资料选进上下文）
        Embedding / 向量库 / Chunking / 混合检索 / Rerank / 评估
                        │
                        │ 光"查资料"不够，还要"会行动"
                        ▼
        W4 Agent（怎么让模型用工具做事）
        ReAct / Function Calling / 并行调用 / MCP / 四大模式
```

一句话串全部：**模型每步都在词表上采样（W1）；提示词决定它"怎么答"（W2）；
检索决定它"拿什么答"（W3）；工具循环决定它"能干什么"（W4）。**

## 2. W2 Prompt → 核心结论与 demo

| 知识点 | 一句话结论 | 我自己的实证 | 出处 |

## 3. W3 RAG → 核心结论与 demo（本仓库最完整的一条线）

整条链路：`w3data/corpus`（15 篇语料）→ `w3data/eval_set.json`（15 题黄金集）
→ `w3data/ragkit.py`（共享库）→ 六天实验。

| 知识点 | 一句话结论 | 我自己的实证数字 | 出处 |
|---|---|---|---|
| Embedding | 语义向量认"意思"，词袋认"字面" | 同义改写对：语义 0.727 vs 词袋 0.125 | w3day01 |
| 向量库 | 检索语义=余弦 top-k，ANN 只提速 | 3 组查询与暴力遍历全对账一致 | w3day02 |
| 最小 RAG | 带引用+弃权的 prompt 是生成的地基 | Recall@5=0.867，弃权率 100% | w3day03 |
| Chunking | 太小有害、太大讨好评；MRR 才看排序 | recursive-150 Recall 0.667 全场最差 | w3day04 |
| 混合检索 | BM25 与向量强项互补，RRF 融合 | Recall@5 0.867→0.933 | w3day05 |
| Rerank | cross-encoder 互相看见，排序更准 | MRR 0.639→0.717，代价 3s/题 | w3day05 |
| RAGAS 评估 | 四指标分层定位：先检索后生成 | top5→top3：Precision↑ Recall↓ 的 trade-off | w3day06 |

**错误分析三个经典案例**（面试可讲）：
1. Q12 多跳题：检索漏了 FC 四步的 chunk，模型基于残缺上下文**正确弃权**
   ——锅在检索层不在生成层。
2. Q11 多跳题：三个 gold 关键词被切进三个 chunk，检索和重排都救不了
   ——要回切分层修（父子块/更粗粒度）。
3. LLM-judge 把"资料中没有 X"的弃权元陈述当成需支持的论断，faith 虚低
   ——rubric 要显式豁免弃权表述。

## 6. 阶段一遗留问题（带进阶段二）

1. **Q11 类多跳问题**：信息被切散时检索救不了——阶段二试 LangChain 的
   ParentDocumentRetriever（父子块）验证。
2. **LLM-judge 校准**：目前 judge 与生成同模型，需要人工标注 50 条算一致率。
3. **工具协议的网关差异**：tool_choice 部分档位未落实——阶段二用 LangChain
   的工具抽象抹平，并保留"客户端兜底校验"习惯。
4. **Agent 成本**：ReAct 上下文二次曲线——阶段二研究 memory/checkpointer
   （LangGraph 的 checkpoint 机制）。

## 7. 一页速览（考前/面试前 5 分钟看这节）

1. **W1**：注意力=按相关性加权读取；温度改分布形状；token=钱；MoE=容量与成本解耦。
2. **W2**：结构化提示词买稳定性；System 是宪法；Mode 管 JSON 语法、Schema 管字段；
   Context Engineering=预算+压缩+记忆分层。
3. **W3**：两条流水线；递归切分是默认；hybrid+RRF+rerank 是标准漏斗；
   评估分层，先检索后生成；小而静的库不用 RAG。
4. **W4**：ReAct 是一切的地基；FC 四步+finish_reason 状态机；并行=sum→max；
   MCP=USB（Host/Client/Server）；四大模式从简到繁逐步加。
