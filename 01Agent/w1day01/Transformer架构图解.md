## 1. 全景图：Encoder–Decoder 结构

先画整体，再逐块拆解。**画图顺序建议：先画两个大盒子，再从下往上填内部结构。**

```
                        Transformer（Encoder–Decoder）

  输入序列                          输出序列（自回归，一次生成一个 token）
  "我 爱 猫"                          "I love cats"
      │                                    ▲
      ▼                                    │
┌─────────────┐                    ┌─────────────┐
│  Encoder    │                    │  Decoder    │   ← N=6 层堆叠
│  (N=6 层)   │─── K, V ──────────▶│  (N=6 层)   │
└─────────────┘                    └─────────────┘
      │                                    ▲
      ▼                                    │
 ┌─────────┐                         ┌───────────┐
 │Input    │                         │Output     │
 │Embedding│                         │Embedding  │
 │+ 位置编码│                         │+ 位置编码  │
 └─────────┘                         └───────────┘
```

**两个关键事实：**

1. Encoder 和 Decoder 各自都是 **N=6 层完全相同的结构堆叠**（只是参数独立）。
2. Encoder 的输出以 **K、V** 的身份注入 Decoder 的每一个 Encoder-Decoder Attention 层——这是"翻译"发生的地方。

## 2. 单个 Encoder 层的内部结构（自下而上画）

```
        x ∈ ℝ^(n×d_model)          ← 上一层的输出（n 个 token，每个 d_model=512 维）
            │
            │   ┌──────────────────────────────────────┐
            ├──▶│ ① Multi-Head Self-Attention           │
            │   │    每个 token "看见"句中所有 token     │
            │   └───────────────┬──────────────────────┘
            │                   │  Attn(x)
            │         ╲         │         ╱
            │          ╲        │        ╱    ← 残差连接（Residual）
            │           ╲       │       ╱       把原始 x 原封不动加上去
            └────────────╲──────┼──────╱
                          ╲     │     ╱
                           ╲    │    ╱
                            ╲   │   ╱
                             ┌──┴──▼──┐
                             │  Add   │   x + MultiHead(x)
                             └───┬────┘
                                 │
                          ┌──────▼──────┐
                          │ LayerNorm   │   归一化到均值0/方差1 再缩放平移
                          └──────┬──────┘
                                 │
            │   ┌──────────────────────────────────────┐
            ├──▶│ ② Feed-Forward Network (FFN)          │
            │   │    每个 token 独立过同一个 MLP          │
            │   │    FFN(x) = max(0, xW₁+b₁)W₂+b₂     │
            │   │    维度: 512 → 2048 → 512             │
            │   └───────────────┬──────────────────────┘
            │                   │  FFN(·)
            │         ╲         │         ╱
            │          ╲        │        ╱   ← 又一个残差连接
            └────────────╲──────┼──────╱
                          ╲     │     ╱
                           ╲    │    ╱
                             ┌──┴──▼──┐
                             │  Add   │
                             └───┬────┘
                                 │
                          ┌──────▼──────┐
                          │ LayerNorm   │
                          └──────┬──────┘
                                 │
                                 ▼
                       输出到下一层 Encoder
```

**一句话记忆：Encoder 层 = Attention ⊕ 残差 ⊕ LayerNorm，然后 FFN ⊕ 残差 ⊕ LayerNorm。**

## 3. 单个 Decoder 层的内部结构（比 Encoder 多一个模块）

```
        y（已生成的部分，如 "I love"）
            │
            ▼
    ┌───────────────────┐
    │ Masked Multi-Head  │ ← ① 带因果掩码的自注意力
    │ Self-Attention     │    只允许看 ≤ 当前位置的 token
    │ (Causal Mask)      │    mask: 上三角全为 -∞
    └─────────┬──────────┘
              │  ⊕残差 ⊕ LayerNorm
              ▼
    ┌───────────────────┐
    │ Encoder-Decoder    │ ← ② 交叉注意力（跨模态/跨语言的桥）
    │ Cross-Attention    │    Q 来自 Decoder！
    │                    │    K, V 来自 Encoder 输出！
    └─────────┬──────────┘    ← 侧向箭头：Encoder ──K,V──▶ 这里
              │  ⊕残差 ⊕ LayerNorm
              ▼
    ┌───────────────────┐
    │ Feed-Forward (FFN) │ ← ③ 与 Encoder 的 FFN 完全一样
    └─────────┬──────────┘
              │  ⊕残差 ⊕ LayerNorm
              ▼
        输出到下一层 Decoder
```

### Masked Self-Attention 的掩码长这样（n=4）

```
        能看见 ▶  ┌─────────────────────┐
    token j →    │  0    -∞   -∞   -∞  │  ← 位置0 只能看自己
    位置 i       │  0     0   -∞   -∞  │  ← 位置1 看 0,1
    ↓            │  0     0    0   -∞  │  ← 位置2 看 0,1,2
                 │  0     0    0    0  │  ← 位置3 看全部
                 └─────────────────────┘
                 softmax 后 -∞ 变成权重 0 → 未来信息进不来
```

**为什么必须掩码？** 训练时 Decoder 拿到的是完整的目标序列（teacher forcing），
不掩码的话第 2 个位置就能抄第 3 个位置的答案，模型学不到"预测下一个词"。

## 4. 自注意力层内部：Multi-Head 的数据流

```
            x (n × 512)
            │
     ┌──────┼──────┬──────┐          8 个头，每个头 512/8 = 64 维
     ▼      ▼      ▼      ▼
   Head1  Head2  ...   Head8         每个头各自算一遍
   Attn   Attn          Attn         Attention(QW_i, KW_i, VW_i)
     │      │      │      │
     └──────┴──────┼──────┘
                   ▼
              Concat (n × 512)       8 个 64 维拼回 512
                   │
                   ▼
               W_O (线性投影)          让模型学会融合 8 个头
                   │
                   ▼
              输出 (n × 512)
```

**为什么要多头？** 单头注意力每个位置只能产出一个"加权平均"；
多头让不同的头学习不同的关系——比如一个头盯主谓一致、一个头盯指代、一个头盯语序。
类似 CNN 的多个卷积核。

## 5. 残差连接 + LayerNorm：为什么每个模块都这样包

```
        输入 x ──────────────┐
            │                │  ← 直通通道（identity path）
            ▼                │
       [子层: Attn / FFN]    │
            │                │
            ▼                │
         Add (x + ·) ◀───────┘
            │
            ▼
        LayerNorm
            │
            ▼
          输出
```

写成公式：

```
LayerNorm(x + Sublayer(x))
```

**两者各自的作用：**

| 组件 | 解决什么问题 |
|---|---|
| **残差连接** | 给梯度一条"高速公路"。深层网络（6层堆起来）如果每一层都必须完整变换输入，梯度连乘会指数级消失/爆炸；有了 `+x`，梯度可以直接沿直通通道回传，`∂out/∂x = 1 + ∂Sub/∂x`，永远 ≥ 1 的分量存在 |
| **LayerNorm** | 把每个样本的每个特征（沿特征维）归一化到稳定分布：`y = (x-μ)/σ · γ + β`，γ/β 可学习。避免深层中激活值漂移到饱和区，让学习率不用小心翼翼 |

**LayerNorm vs BatchNorm（面试常问）：**

- BatchNorm 沿 batch 维归一化 → 依赖 batch 大小，变长序列/小 batch 不稳定
- LayerNorm 对每个样本独立归一化 → 与 batch 无关、与序列长度无关，**天生适合 NLP**

## 6. 位置编码（Positional Encoding）：注意力本身没有"顺序"

Self-Attention 是集合运算——把句子打乱，输出只是跟着打乱，注意力权重完全不变。
所以必须**显式注入位置信息**：

```
输入 "我 爱 猫"
  │
  ▼
Embedding:  "我"→[0.2, -0.5, ...]   每个 token 一个 512 维向量
  │
  ▼
位置编码 PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
       PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
  │
  ▼
相加：  x = TokenEmbedding + PE        ← 注意是 ⊕ 相加，不是 concat
```

不同维度用不同频率的正/余弦，像给每个位置发一条不同波长的"相位信号"。

> 论文原文用固定正弦编码；后来 BERT/GPT 用**可学习的位置嵌入**；
> 再后来 RoPE（旋转位置编码，LLaMA 系）把位置直接旋进 Q/K，外推性更好。

## 7. 完整数据流：用一个具体例子走一遍

句子："我 爱 猫" → "I love cats"

```
① "我 爱 猫" ──tokenize──▶ [3, 7, 12]（查词表得到整数 ID）

② [3, 7, 12] ──Embedding 查表──▶ X ∈ ℝ^(3×512)

③ X + PE ──▶ 位置感知的输入

④ 进入 Encoder ×6 层：
   每层里，"猫" 的 Query 会和 "我/爱/猫" 的 Key 全部算点积。
   比如 "猫" 的 q·k("爱") 分数高 → "猫" 的新表示里融入了"被爱"的语义。
   6 层堆叠 = 语义不断抽象（低层学语法，高层学语义）

⑤ Encoder 最终输出 H_enc ∈ ℝ^(3×512)，它是 K、V 的矿藏。

⑥ Decoder 侧：
   输入 "<start> I love" ──Embedding+PE──▶ 进入 Decoder ×6 层
   每层:
     - Masked Self-Attention：让 "love" 看见 "<start>" 和 "I"（看不见未来）
     - Cross-Attention：用 Decoder 的 Q 去查 Encoder 的 K，
                        对齐源语言！  ← 翻译的"对齐矩阵"就可视化在这里
                        （"I" ↔ "我", "love" ↔ "爱"）
     - FFN：非线性变换

⑦ Decoder 顶层输出 ℝ^(3×512) ──Linear(→词表大小)──▶ logits

⑧ logits ──softmax──▶ 概率分布 ──采样──▶ 下一个词 "cats"

⑨ 把 "cats" 拼回输入，重复 ⑥-⑧，直到生成 <end>
```

## 8. 核心问题：为什么 Transformer 比 RNN 好？

### 8.1 逐项对比

```
   RNN/GRU/LSTM                          Transformer
 ─────────────────────                ─────────────────────
 处理序列：                          处理序列：
  x1→h1→x2→h2→x3→h3→...              x1 ─┐
  （串行，一步算一个）                 x2 ─┼─▶ 全部 token 并行算注意力
                                       x3 ─┘   （一步全算完）

 第 3 个词的信息到第 1 个词：        第 3 个词到第 1 个词：
 必须经过 h2 这一"站"，               直接一条边 Q3·K1，
 路径长度 = 距离                      距离恒为 1
```

### 8.2 三个决定性优势

| # | 优势 | 机制解释 |
|---|---|---|
| **1** | **并行计算（训练快）** | RNN 的 h_t 依赖 h_{t-1}，**时间维无法并行**，GPU 利用率低。Transformer 的自注意力对 n 个位置完全并行——这就是为什么 GPT 能用几千卡训练而 LSTM 时代做不到 |
| **2** | **长程依赖路径长度 O(1)** | RNN 里相隔 100 个词的两个 token，信息要穿越 100 次矩阵乘，**梯度连乘 100 次**，早期几乎必然消失。自注意力任意两个 token 直接交互，路径长度恒为 1，第 5000 个词和第 1 个词"零距离" |
| **3** | **动态权重，表达力更强** | RNN 对整个序列用同一组循环权重（时间共享）；注意力的权重是**根据内容现算的**——"看什么"随语境变化。处理 "苹果发布了新手机" 和 "我吃了苹果" 时，"苹果" 的注意力分布完全不同 |

### 8.3 一个直观比喻

- **RNN** 像口耳相传的传话游戏：第 1 个人说的信息，传到第 100 个人时早已失真。
- **Transformer** 像圆桌会议：每个人（token）都能直接听到其他所有人的发言，并自行决定重点听谁的。

### 8.4 诚实的另一面：代价

| 代价 | 说明 |
|---|---|
| 计算复杂度 O(n²) | 每层 n×n 的注意力矩阵，序列翻倍计算量 ×4。长上下文（100K+）需要 FlashAttention、稀疏注意力、滑动窗口（Mistral）等技巧 |
| 无归纳偏置 | RNN 天然假设"顺序重要"、CNN 天然假设"局部相邻"；Transformer 对位置、局部性一无所知，全靠数据学出来 → 需要大数据量才显优势 |
| 显存 | n×n 注意力矩阵 + KV Cache 都吃显存，推理长上下文时尤其明显 |

> **历史注脚**：2017 年论文里 Transformer 只是翻译模型（Encoder-Decoder）。
> 后来 GPT 只留 Decoder（因果语言模型），BERT 只留 Encoder（双向理解）。
> 现在的大语言模型几乎都是 **Decoder-only**——即上文第 3 节那张图。
